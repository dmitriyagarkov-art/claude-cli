# Claude на своём сервере

Установщик и страница-гайд: как поднять Claude Code с веб-панелью на собственном
VPS и заходить в него по своему домену без VPN.

Автор гайда: [dmitriymarketing](https://t.me/dmitriymarketing)

---

## Что здесь лежит

```
claude-server/
├── public/
│   ├── index.html      страница-гайд (то, что видит пользователь)
│   └── install.sh      установщик, запускается на сервере пользователя
├── vercel.json         настройки хостинга
└── README.md           этот файл
```

---

## Как это работает у пользователя

1. Арендует любой VPS: Ubuntu 24.04, 4 ГБ памяти, Германия или Нидерланды
2. Прописывает A-запись `claude.свой-домен.ru` на IP сервера
3. Подключается: `ssh root@IP`
4. Вставляет одну команду
5. Отвечает на два вопроса (домен и почта) и выбирает, как подключить аккаунт Claude
6. Открывает свой адрес в браузере, входит по логину и паролю с экрана

Команда установки:

```bash
bash -c "$(curl -fsSL https://ВАШ-ДОМЕН/install.sh)"
```

## Что делает установщик

| Шаг | Действие |
|-----|----------|
| 1 | Проверки: root, Ubuntu/Debian, память, место на диске |
| 2 | Подкачка 2 ГБ, если памяти меньше 8 ГБ |
| 3 | `apt` пакеты, включая сборочные для нативных модулей |
| 4 | Node.js 22 из NodeSource |
| 5 | `@anthropic-ai/claude-code` |
| 6 | `@cloudcli-ai/cloudcli` (веб-панель, порт 3001 на localhost) |
| 7 | Ждёт, пока домен начнёт резолвиться на IP сервера |
| 8 | systemd-служба `claude-panel` с автозапуском |
| 9 | Caddy: реверс-прокси на 3001 плюс автоматический Let's Encrypt |
| 10 | UFW (открыты только 22, 80, 443) и fail2ban |
| 11 | Генерит пароль и создаёт учётку `admin` через API панели |
| 12 | Ставит команды-помощники |
| 13 | Подключает аккаунт Claude: вход по ссылке или перенос с компьютера |

Установщик **идемпотентен**: можно запускать повторно, ранее созданный пароль не
затирается, уже установленные компоненты пропускаются.

### Команды на сервере после установки

```
claude-status           проверить состояние всех служб
claude-update           обновить Claude Code и панель
claude-login            подключить или перевойти в аккаунт Claude
claude-reset-password   задать новый пароль от панели
claude-uninstall        удалить всё
```

Доступы дублируются в `/root/claude-server-info.txt` (права 600).
Лог установки: `/var/log/claude-server-install.log`.

### Неинтерактивный режим

```bash
DOMAIN=claude.site.ru EMAIL=me@mail.ru bash -c "$(curl -fsSL https://ВАШ-ДОМЕН/install.sh)"
```

Переопределяемые переменные: `DOMAIN`, `EMAIL`, `PANEL_PORT` (по умолчанию 3001).

## Публикация на Vercel

### Через GitHub

1. Создать репозиторий и залить эти файлы
2. На vercel.com нажать **Add New → Project**, выбрать репозиторий
3. Framework Preset: **Other**. Build Command и Install Command оставить пустыми.
   Output Directory: `public`
4. Deploy

Дальше каждый `git push` обновляет страницу автоматически.

### Через CLI

```bash
npm i -g vercel
cd claude-server
vercel --prod
```

### После деплоя

Проверить, что установщик отдаётся как обычный текст:

```bash
curl -fsSL https://ВАШ-ДОМЕН/install.sh | head -20
```

Затем **поменять адрес в двух местах**:

- `public/index.html`, блок Шага 5, там команда установки (в тексте и в кнопке копирования)
- `README.md`, если хотите

Ищите строку `claude-server.vercel.app` и меняйте на свой домен.

## Как протестировать самому

1. Взять самый дешёвый VPS на 4 ГБ в Германии, Ubuntu 24.04
2. Прописать A-запись на его IP
3. `ssh root@IP`
4. Запустить установщик
5. Пройти по всем трём вариантам подключения аккаунта (в разных прогонах)
6. Проверить `claude-status`, перезагрузить сервер (`reboot`), проверить,
   что панель поднялась сама
7. Проверить открытие с телефона по мобильному интернету без VPN
8. В конце `claude-uninstall` и удалить сервер

## Технические заметки

**Панель слушает 0.0.0.0:3001.** Наружу порт закрыт фаерволом, снаружи доступ
только через Caddy по 443. Если пользователь отключит UFW, панель окажется
доступна по `http://IP:3001` без шифрования. Стоит это упомянуть, если будете
дописывать гайд.

**Всё работает от root.** Это сознательное упрощение: личный сервер одного
человека, Claude Code должен свободно писать файлы. Для многопользовательского
сценария нужен отдельный системный пользователь.

**Один аккаунт Claude на сервер.** Раздача доступа к панели нескольким людям с
одной подпиской нарушает условия Anthropic и ведёт к блокировке аккаунта.

**Версии не запинены** — ставится `@latest`. Это удобно для свежих установок, но
если панель выпустит ломающее обновление, новые установки могут отвалиться.
Если захотите стабильности, замените в `install.sh`:

```bash
PANEL_PKG="@cloudcli-ai/cloudcli"   →   ставится как $PANEL_PKG@latest
```

на конкретную версию, например `@1.37.0`.

**Проверенные версии на момент сборки:** Claude Code 2.1.220, CloudCLI 1.37.0,
Node 22, Ubuntu 24.04.
